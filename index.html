Дыбыс сенсоры және LED индикаторы

Дыбыс мәнін оқып, 500 шекті көрсеткішпен салыстыратын автоматты жүйе.

Сенсор A0LED D13Шек 500Serial 9600

1. Жобаның мақсаты

Дыбыс сенсорының аналогтық көрсеткішін оқып, мән шектен асқанда LED шамын автоматты қосу.

01 • Өлшеу

A0 портынан analogRead() арқылы сенсор мәнін алу.

02 • Салыстыру

Мәнді 500 шекті көрсеткішімен тексеру.

03 • Басқару

HIGH — LED жанады; LOW — өшеді.

2. Инфографика — алгоритм

Дыбыс > 500
LED ЖАНАДЫ
⇄
Дыбыс ≤ 500
LED ӨШЕДІ

3. Қосылу порттары

AO → A0Аналогтық сенсор шығысы
LED → D13Жарық диодын басқару
VCC / GNDҚорек және ортақ жер

Сенсордағы нақты pin атауларын тексеріңіз. Сыртқы LED үшін резистор қолданыңыз.

4. Arduino C++ коды (Arduino IDE)

int soundSensor = A0;
int ledPin = 13;
int threshold = 500;

void setup() {
  pinMode(ledPin, OUTPUT);
  Serial.begin(9600);
}

void loop() {
  int sensorValue = analogRead(soundSensor);
  Serial.println(sensorValue);

  if (sensorValue > threshold) {
    digitalWrite(ledPin, HIGH); // Шам жанады
  } else {
    digitalWrite(ledPin, LOW);  // Шам өшеді
  }
  delay(10);
}

5. Google Colab — Python симуляциясы

Colab-та сенсор орнына мысал мәндер қолданылады. Код ұяшықтарын ретімен орындаңыз.

5.1 Сенсор мәндері

threshold = 500
sensor_values = [120, 260, 480, 520, 650, 430, 700, 310, 510, 180]

led_states = []
for value in sensor_values:
    state = "ЖАНАДЫ" if value > threshold else "ӨШІК"
    led_states.append(state)
    print(f"Дыбыс: {value} | LED: {state}")

5.2 Диаграмма

import matplotlib.pyplot as plt

plt.figure(figsize=(10, 5))
plt.plot(range(1, len(sensor_values)+1), sensor_values,
         marker="o", label="Сенсор мәні")
plt.axhline(threshold, linestyle="--", label=f"Шек = {threshold}")
plt.xlabel("Өлшеу нөмірі")
plt.ylabel("Дыбыс сенсорының мәні")
plt.title("Arduino дыбыс сенсоры — симуляция")
plt.xticks(range(1, len(sensor_values)+1))
plt.grid(True)
plt.legend()
plt.show()
